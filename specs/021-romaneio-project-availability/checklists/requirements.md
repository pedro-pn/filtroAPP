# Checklist de qualidade da especificação

- [x] O comportamento de Saída distingue projeto gerenciado de legado.
- [x] A definição de obra antiga/concluída está registrada.
- [x] O comportamento aberto de Entrada está explícito.
- [x] Regras de acesso e exclusão lógica foram preservadas.
- [x] A proteção contra chamada direta foi incluída.
- [x] A troca de tipo e o código manual foram especificados.
- [x] Não há mudança de banco ou dependência de CRM.
