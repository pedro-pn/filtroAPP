# Checklist de qualidade da especificação

- [x] A nova etapa e sua regra de entrada estão explícitas.
- [x] A preservação da autorização durante a execução está coberta.
- [x] As fontes de avanço, RDOs e relatórios técnicos foram definidas.
- [x] A ausência de fonte automática para RLR está tratada sem inventar dados.
- [x] Os desvios reutilizam o módulo Qualidade.
- [x] Campos, categorias e permissões dos desvios estão definidos.
- [x] Persistência, validação, responsividade e campanha de novidade estão cobertas.
